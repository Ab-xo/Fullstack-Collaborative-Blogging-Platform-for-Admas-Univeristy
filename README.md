# Admas Community

A full-stack collaborative blogging platform for Admas University. The application combines publishing, real-time collaboration, AI-assisted writing, personalized feeds, role-based access control, and moderation workflows.

## Features

- Article creation, editing, publishing, and discovery
- Personalized feeds and community interactions
- Real-time features powered by Socket.io
- AI content assistance
- Role-based access control and moderation
- Responsive React interface
- Deployment configurations for Netlify and Render

## Technology

- React, Vite, Tailwind CSS
- Node.js and Express
- MongoDB and Mongoose
- Socket.io
- JWT authentication

## Getting started

Install dependencies in the root and application directories according to the project package scripts, configure the client and server environment variables, then start the frontend and backend services.

```bash
npm install
npm run dev
```
